# 红二记分

阿薛的五人红二记分 App。纯静态 PWA，无账号、无后端、无远程接口。

## iPhone 安装

将整个目录放在固定 HTTPS 网址下。用 Safari 打开网址，点“分享”→“添加到主屏幕”。首次联网打开、离线资源缓存完成后可离线记分。建议 iOS 16.4 或更新版本。

记分只存在当前设备和当前网址中。不同网址、Safari 与主屏幕 App 的存储可能隔离，迁移时使用“首页 → 备份与安装”。清理网站数据或系统回收存储可能删除本机记录，请把重要牌局的 JSON 备份存到“文件”或 iCloud。

## 使用

- 普通局：点赢家、点番数、点抓几家，直接入账。
- 奖励：点玩家下的“＋奖励”，弹窗点一项后自动收起。相同选项再点可取消；“清除”取消该玩家全部奖励。
- 三红二：奖励中选“三红二”后，结果变成“抓四家 / 和局 / 输四家”。结果数字包含奖励。
- 总览结束本场，历史牌局可回顾全部逐局明细。可以撤销最新一局、继续刚结束的一场。
- 自动保存失败时操作会回滚，不会假装入账。记录损坏时尝试上一份存档。恢复备份前保留原记录，可撤销恢复。

## 规则

- 抓一至三家底分 3 / 6 / 9，输家每人扣 `min(底分 × 2^番数, 80)`。赢家平分输分池，整数余数按座位顺序分配。
- 三红二抓四家：每位对手付 `min(12 × 2^番数, 300)`。输四家：本人向四人各付 `min(3 × 2^番数, 80)`。和局牌局分为零。
- 7～12 同总奖励 80 / 120 / 200 / 400 / 2000 / 4000；三红二总奖励 120。其他四人平摊，奖励叠加、不翻番、不封顶、输局也拿。

## 本地预览

在此目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765`。本机 localhost 适用于测试；iPhone 安装和离线功能须使用 HTTPS。

无需构建。上线时保留整个目录结构。更新离线资源时同时修改 `sw.js` 的 CACHE 版本；旧页面全部关闭后使用新版本。

图标使用本地打包的 Lucide 0.468.0，许可证见 assets/lucide-LICENSE。没有云端同步、App Store 安装包或广告。
